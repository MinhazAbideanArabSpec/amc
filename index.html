🌐 GitHub Hosting

Lets clients publish website updates from their own Website tab. The portal commits directly to each client's connected repo — set the token here once, then connect each client's repo from Clients → Website. Requires the server-side setup in supabase/HOSTING_SETUP.md to be completed once.

💾 Database Backup

Downloads every table's data as a .zip of JSON files, straight to your computer. Excludes SMTP/GitHub credentials — those are re-entered, not restored.

📈 Vercel Analytics

Lets clients see their site's visitor stats from their own Website tab. Set the token here once, then connect each client's Vercel project from Clients → Website.

✉️ Email Alerts (SMTP)

Sends automatic reminder emails to admins, the customer, and their staff when a contract or software renewal is 60, 30, 14, or 7 days from expiring. Requires the server-side setup in supabase/SETUP.md to be completed once.
Sends 2 sample emails (one contract-style, one software-renewal-style) using the exact same template real alerts use, clearly marked as tests.

📣 Send Marketing Email

Upload an Excel (or CSV) file — every cell that looks like an email address is picked up automatically, regardless of column layout. Anyone who has unsubscribed before is skipped, and an unsubscribe link is added to every email automatically. Sent via the SMTP account configured above, so keep lists reasonably sized.
